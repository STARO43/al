# ЛОГАРИФМ · АП-2 — кино-редакция

Интерактивная образовательная история: терминал советской ЭВМ «РУБИН»,
абонентский пункт АП-2, переписка с неизвестным абонентом, который угадывает
ваше число от 1 до 100 000 за 17 вопросов — и раскрывает, что такое логарифм.

Восемь сеансов + тренажёр. Весь образовательный контент, диалоги и
разборы ошибок сохранены из исходной версии.

## Запуск

- **Самодостаточный файл**: откройте `ЛОГАРИФМ_АП-2.html` в любом браузере —
  всё (CSS, JS, шрифты) зашито внутрь, интернет не нужен.
- **Как проект**: откройте `index.html` через локальный сервер
  (`python3 -m http.server`), либо просто двойной клик по `index.html`.

## Что внутри (архитектура)

| Файл | Роль |
| --- | --- |
| `js/core.js` | Движок сеансов: печать телетайпом, выборы с разбором ошибок, умный автоскролл, HUD «Пульт хода», карточки формул |
| `js/shader.js` | WebGL-фон (зерно плёнки, дым, виньетка) и переходы между сеансами в духе GL Transitions: noise / pixel / wave / ripple / zoom с рубиновой кромкой |
| `js/kinetic.js` | Кинетическая типографика (референс Typos): титры сеансов, полноэкранные слова, финальный плакат; буквы деформируются вблизи курсора |
| `js/viz.js` | Canvas-визуализации: поле 100 000 вариантов, каскад деления, лестница степеней, график 2ˣ/log₂ с пробой курсора, морф линейной↔логарифмической шкалы, децибелы, сейсмограф, сложные проценты, поток цифр 2¹⁰⁰ |
| `js/ascii.js` | Статус игры (питает HUD), итоговая карточка «Ход поиска», совместимые имена A.* |
| `js/sfx.js` | Синтезированный звук (WebAudio): телетайп, модем, помехи, переходы. Выключен по умолчанию — кнопка ЗВУК |
| `js/sc01…sc08.js, lab.js` | Сценарий сеансов и тренажёр |

## Ключевые исправления против старой версии

1. **Шкала вариантов в первой сцене больше не уезжает.** Счётчик «вопрос n/17 ·
   осталось вариантов · диапазон» живёт на закреплённом **Пульте хода** (справа
   на десктопе, снизу на телефоне) и виден во время всех 17 вопросов. По
   завершении игры в ленту печатается итоговая карточка «Ход поиска».
2. **Умный автоскролл**: если вы листаете ленту вверх, печать не дёргает её;
   появляется плашка «▼ показать новое». Внизу лента ведёт себя как раньше.
3. Все графики — контрастные, с крупными подписями, поддержкой тача и
   `prefers-reduced-motion` (мгновенный финальный кадр).
4. Убран кислотно-зелёный «хакерский» визуал: палитра «РУБИН» — уголь,
   бумага, рубин, янтарь, сталь.

## Шрифты

Unbounded (дисплей) и JetBrains Mono (терминал), оба под OFL; в репозиторий
включены сабсеты woff2 (кириллица, латиница, математика, стрелки, ₽).

Управление: [1–9] — выбор варианта, пробел/клик — ускорить печать,
клик/пробел — закрыть полноэкранный типографический момент.
