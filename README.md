# LOGARITHM — вопрос, который меняет масштаб

Интерактивное образовательное путешествие в мир логарифмов: 8 эпизодов + тренажёр, ~10 минут прохождения. Полностью статический сайт без backend — создан для публикации на **GitHub Pages**.

## Структура проекта

```
logarithm/
├── index.html          — разметка приложения (интро, сцена, док управления, субтитры)
├── styles.css          — дизайн-система (DARK SCIENCE, кинетическая типографика, адаптив)
├── README.md
└── js/
│   ├── core.js         — утилиты, цветовое кодирование формул, движок эпизодов, прогресс, фон
│   ├── voice.js        — озвучка (Web Speech API, ru-RU) и синхронизация субтитров
│   ├── transitions.js  — WebGL-переходы (pixel/noise dissolve, ripple, wave, zoom rays) + CSS-фолбэк
│   ├── e01.js … e08.js — восемь эпизодов
│   └── lab.js          — тренажёр (калькулятор, графики, шкала, мини-контроль)
└── assets/images/favicon.svg
```

Папки `assets/audio/` и `assets/fonts/` не созданы намеренно: озвучка работает через системный синтез речи, шрифты — системные (без внешних зависимостей). При желании локальные шрифты кладите в `assets/fonts/` и подключайте в `styles.css`.

## Локальный запуск

Вариант 1 — просто открыть `index.html` двойным щелчком (все скрипты классические, работают с `file://`).

Вариант 2 — мини-сервер (корректнее для speechSynthesis в некоторых браузерах):

```bash
cd logarithm
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

1. Создайте репозиторий, например `logarithm`.
2. Загрузите файлы (через веб-интерфейс — «Add file → Upload files», либо `git init && git add . && git commit -m "init" && git remote add origin … && git push -u origin main`).
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.**
4. Через минуту сайт будет на `https://<логин>.github.io/logarithm/`.

Все пути в проекте относительные (`styles.css`, `js/core.js`), поэтому сайт работает и в корневом репозитории пользователя, и во вложенном пути проектного репозитория.

## Управление и звук

- Озвучка: Web Speech API (`speechSynthesis`), голос выбирается из доступных ru-голосов, скорость 0,7–1,4×. Запуск — только после первого действия пользователя (кнопка «Начать»).
- Субтитры включаются/выключаются, синхронизация по предложениям (границы возможностей браузера).
- Полный текст каждой сцены доступен под сценой («Текст сцены»).
- Клавиатура: `→`/`←` — навигация, `пробел` — озвучка/пауза, `R` — перезапуск эпизода.

## Проверка математической корректности

Все числа вычислены кодом и сверены (см. скрипт проверки в отчёте проекта):

- 2¹⁹ = 524 288; 2²⁰ = 1 048 576; log₂(1 000 000) ≈ 19,9315686 → ⌈·⌉ = 20 вопросов
- log₂8 = 3; log₃81 = 4; lg(1000) = 3; log₅1 = 0; log₂(1/8) = −3; log₉3 = 1/2
- 2¹⁰⁰ = 1 267 650 600 228 229 401 496 703 205 376 — ровно 31 цифра (проверено BigInt)
- Правило цифр: ⌊lg N⌋ + 1 (в тренажёре — точный BigInt и формула рядом)
- 60→120 дБ = ×10⁶ интенсивности; +10 дБ = ×10 (без смешения с громкостью/давлением)
- +1 магнитуда: амплитуда ×10, энергия ×10^1,5 ≈ ×31,6 (магнитуда ≠ сила сотрясений)
- 1,12ⁿ = 2 → n ≈ 6,12; первый целый год с суммой ≥ ×2 — седьмой (1,12⁶ ≈ 1,974 < 2 ≤ 1,12⁷ ≈ 2,211)
- 2³³ = 8 589 934 592 ≥ 8 000 000 000 → 33 вопроса

## Известные ограничения

- **Голоса:** состав ru-голосов зависит от устройства/браузера. На iOS Safari каждая озвучка может требовать нового касания экрана. Нет голосов — весь материал остаётся доступным текстом и субтитрами.
- **Субтитры:** посегментная (по предложениям) синхронизация; посимвольной синхронизации Web Speech API не даёт.
- **WebGL:** переходы деградируют к CSS-фолбэку при отсутствии WebGL; сайт полностью работоспособен без GPU.
- **Reduced motion:** при `prefers-reduced-motion: reduce` отключаются частицы, зерно и тяжёлые анимации; переходы — быстрый фейд.
- **TTS-пауза:** кнопка ⏸ использует `speechSynthesis.pause()`; в ряде Android-браузеров она имитируется отменой и перезапуском текущего сегмента — тогда позиция внутри предложения не сохраняется.
